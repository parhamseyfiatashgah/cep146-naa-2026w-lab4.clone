\*\*What is the difference between a git "merge" and a GitHub "pull request"?\*\*



A \*\*git merge\*\* is a Git command that combines changes from one branch into another in a local repository (or any Git repo).



A \*\*GitHub pull request\*\* is a GitHub feature used to propose changes (often from a branch or fork) and allows review/discussion before merging into the target branch.
